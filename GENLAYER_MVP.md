# Reality Bridge MVP

The current GenLayer MVP is Reality Bridge, a hidden-choice elimination game
settled by validator consensus on GenLayer StudioNet.

The authoritative product and architecture documents are maintained with the
submission:

- [`apps/reality-bridge/specs/PRODUCT_SPEC.md`](apps/reality-bridge/specs/PRODUCT_SPEC.md)
- [`apps/reality-bridge/specs/ARCHITECTURE.md`](apps/reality-bridge/specs/ARCHITECTURE.md)
- [`apps/reality-bridge/SECURITY.md`](apps/reality-bridge/SECURITY.md)
- [`apps/reality-bridge/SUBMISSION.md`](apps/reality-bridge/SUBMISSION.md)

Those documents define the StudioNet-only network boundary, the pinned GenVM
runner, the commitment/reveal protocol, permissionless liveness paths, and
deterministic settlement rules.
